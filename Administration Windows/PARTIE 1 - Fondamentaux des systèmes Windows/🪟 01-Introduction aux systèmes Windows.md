## 📜 Histoire et évolution de Windows

### Les débuts : l'ère MS-DOS

Avant Windows, Microsoft a créé **MS-DOS** (Microsoft Disk Operating System) en 1981, un système d'exploitation en ligne de commande. MS-DOS était le système dominant des années 1980, mais son interface textuelle limitait son accessibilité au grand public.

> [!info] Pourquoi Windows a été créé
> Windows a été développé pour offrir une interface graphique (GUI) au-dessus de MS-DOS, rendant l'informatique accessible aux utilisateurs non techniques. L'objectif était de concurrencer le Macintosh d'Apple, lancé en 1984.

### Windows 1.0 à 3.x (1985-1994)

**Windows 1.0** (1985)
- Première version avec interface graphique
- Fenêtres en mosaïque (pas de chevauchement)
- Applications limitées (Paint, Calculator, Notepad)
- Échec commercial relatif

**Windows 3.0 et 3.1** (1990-1992)
- Premier véritable succès commercial
- Fenêtres superposables
- Gestionnaire de programmes et de fichiers
- Support amélioré de la mémoire
- Plus de 10 millions de copies vendues

> [!example] Interface Windows 3.1
> Windows 3.1 introduisait le "Program Manager" avec des icônes de groupes de programmes, ancêtre du menu Démarrer moderne.

### L'ère Windows 9x (1995-2000)

**Windows 95** (1995)
- 🎯 Révolution majeure dans l'histoire de l'informatique
- Introduction du **menu Démarrer**
- Barre des tâches
- Support du Plug and Play
- Noms de fichiers longs (jusqu'à 255 caractères)
- Intégration d'Internet Explorer

**Windows 98** (1998)
- Support USB natif
- Lecteur Windows Media
- Amélioration de la stabilité
- Windows 98 SE (Second Edition) : meilleur support internet

**Windows ME** (Millennium Edition, 2000)
- Restauration système
- Windows Movie Maker
- Dernière version basée sur MS-DOS/9x
- ⚠️ Réputé pour son instabilité

> [!warning] Windows ME
> Windows Millennium Edition est souvent considéré comme l'une des pires versions de Windows en raison de problèmes de stabilité fréquents et de compatibilité matérielle.

### L'ère Windows NT et 2000 (Professionnel)

Parallèlement à la gamme grand public (9x), Microsoft développait **Windows NT** pour les entreprises.

**Windows NT 3.1 à 4.0** (1993-1996)
- Architecture 32 bits moderne
- Stabilité et sécurité améliorées
- Multi-utilisateurs
- Support des domaines réseau
- Destiné aux entreprises

**Windows 2000** (2000)
- Fusion progressive entre NT et la gamme grand public
- Active Directory (révolution pour les entreprises)
- Plug and Play amélioré
- Support USB
- Versions : Professional, Server, Advanced Server

### L'ère moderne : Windows XP et Vista

**Windows XP** (2001-2014)
- 🏆 L'une des versions les plus populaires de l'histoire
- Interface graphique Luna colorée
- Stabilité du noyau NT
- Gestion améliorée des utilisateurs
- Support étendu jusqu'en 2014 (13 ans !)
- Versions : Home Edition, Professional, Media Center Edition

> [!tip] Longévité de Windows XP
> Windows XP a été si populaire que de nombreuses entreprises ont résisté à la migration vers des versions plus récentes pendant des années. Son support a duré exceptionnellement longtemps.

**Windows Vista** (2007)
- Interface Aero avec transparence
- User Account Control (UAC)
- Windows Defender intégré
- Exigences matérielles élevées pour l'époque
- ⚠️ Critiqué pour problèmes de compatibilité et lenteurs
- Versions : Home Basic, Home Premium, Business, Ultimate

### Windows 7 à 10 : Maturité

**Windows 7** (2009-2020)
- Réponse aux critiques de Vista
- Interface Aero raffinée
- Meilleures performances
- Bibliothèques de documents
- Support jusqu'en janvier 2020
- ✅ Version très appréciée, considérée comme l'héritier spirituel de XP

**Windows 8 et 8.1** (2012-2013)
- Interface Modern UI (Metro) tactile
- Suppression du menu Démarrer (restauré dans 8.1)
- ⚠️ Mal reçu par les utilisateurs desktop
- Écran de démarrage en plein écran
- Applications universelles (UWP)

**Windows 10** (2015-2025)
- Retour du menu Démarrer (hybride)
- "Dernière version de Windows" annoncée (avant Windows 11)
- Mises à jour continues (Windows as a Service)
- Cortana, assistante virtuelle
- Windows Hello (biométrie)
- Mises à jour fonctionnelles bi-annuelles

> [!info] Windows as a Service
> Avec Windows 10, Microsoft a introduit le concept de "Windows as a Service" : des mises à jour continues plutôt que des versions majeures espacées. Ce modèle a été maintenu avec Windows 11.

### Ligne temporelle Windows Server

**Windows Server** a suivi une évolution parallèle :

```
2003 → Windows Server 2003
2008 → Windows Server 2008 / 2008 R2
2012 → Windows Server 2012 / 2012 R2
2016 → Windows Server 2016
2019 → Windows Server 2019
2022 → Windows Server 2022
```

> [!example] Évolution majeure
> Windows Server 2008 R2 a été la première version serveur exclusivement 64 bits, abandonnant définitivement le support 32 bits côté serveur.

## 💻 Versions Windows Desktop (10, 11)

Lancé en **juillet 2015**, Windows 10 a marqué le retour à une interface familière après l'échec de Windows 8.

#### Éditions Windows 10

**Windows 10 Home**
- 🏠 Édition grand public standard
- Fonctionnalités essentielles (Cortana, Edge, Windows Hello)
- Windows Update automatique (pas de report possible)
- ❌ Pas de jonction à un domaine Active Directory
- ❌ Pas de BitLocker (chiffrement complet)
- ❌ Pas de Hyper-V
- ❌ Pas de Bureau à distance (serveur RDP)

**Windows 10 Pro**
- 💼 Édition professionnelle pour PME
- ✅ Jonction à un domaine Active Directory
- ✅ BitLocker (chiffrement des disques)
- ✅ Hyper-V (virtualisation)
- ✅ Bureau à distance (RDP serveur)
- ✅ Stratégies de groupe locales
- ✅ Windows Update for Business (report de mises à jour)
- ✅ Assigned Access (mode kiosque)

**Windows 10 Pro for Workstations**
- 🖥️ Version haute performance
- Support jusqu'à 4 processeurs physiques
- Support jusqu'à 6 TB de RAM
- Système de fichiers ReFS (Resilient File System)
- Mode de performance persistant
- Destiné aux stations de travail puissantes (CAO, rendu 3D, etc.)

**Windows 10 Enterprise**
- 🏢 Édition pour grandes entreprises
- Toutes les fonctionnalités de Pro
- ✅ DirectAccess (VPN transparent)
- ✅ AppLocker (contrôle d'applications)
- ✅ Windows To Go (démarrage depuis USB)
- ✅ Credential Guard (protection des identifiants)
- ✅ Device Guard (sécurité renforcée)
- ✅ Long Term Servicing Channel (LTSC) disponible
- Licence en volume uniquement

**Windows 10 Education**
- 🎓 Similaire à Enterprise pour les établissements scolaires
- Tarifs académiques réduits
- Destiné aux écoles et universités

> [!tip] Quelle édition choisir ?
> - **Particulier** : Home suffit généralement
> - **PME / Professionnel** : Pro pour jonction au domaine et BitLocker
> - **Grande entreprise** : Enterprise via licence en volume

#### Fonctionnalités clés de Windows 10

**Interface et productivité**
- **Menu Démarrer hybride** : Tuiles dynamiques + liste d'applications
- **Bureaux virtuels** : Multiple Task View (⊞ Win + Tab)
- **Snap Assist** : Organisation des fenêtres par quadrants
- **Timeline** : Historique des activités (retiré dans 21H2)
- **Presse-papiers cloud** : Synchronisation entre appareils

**Sécurité**
- **Windows Hello** : Authentification biométrique (visage, empreinte)
- **Windows Defender** : Antivirus intégré
- **Windows Defender Firewall** : Pare-feu intégré
- **Controlled Folder Access** : Protection ransomware
- **Microsoft Defender SmartScreen** : Protection web

**Système et administration**
- **Paramètres** : Interface moderne (progressivement remplace le Panneau de configuration)
- **Windows Subsystem for Linux (WSL)** : Exécuter Linux nativement
- **Windows Sandbox** : Environnement isolé temporaire
- **PowerShell 5.1** : Langage de script et d'administration
- **Storage Sense** : Nettoyage automatique du disque

### Windows 11 : La nouvelle génération

Lancé en **octobre 2021**, Windows 11 représente une refonte visuelle et fonctionnelle majeure.

#### Cycle de vie de Windows 11

| Version | Date de sortie | Fin du support (Home/Pro) | Fin du support (Enterprise/Education) |
|---------|----------------|---------------------------|--------------------------------------|
| 21H2 (Build 22000) | Octobre 2021 | Octobre 2023 | Octobre 2024 |
| 22H2 (Build 22621) | Septembre 2022 | **Octobre 2024** | **Octobre 2025** |
| 23H2 (Build 22631) | Octobre 2023 | Octobre 2025 | Octobre 2026 |

> [!info] Support plus court pour Home/Pro
> Les éditions Home et Pro de Windows 11 ont un support de 24 mois, contre 36 mois pour Enterprise et Education.

#### Éditions Windows 11

Les éditions sont similaires à Windows 10, avec les mêmes noms :

- **Windows 11 Home**
- **Windows 11 Pro**
- **Windows 11 Pro for Workstations**
- **Windows 11 Enterprise**
- **Windows 11 Education**

Les différences fonctionnelles entre les éditions restent identiques à Windows 10.

#### Nouveautés de Windows 11

**Interface utilisateur**
- 🎨 **Design Fluent** : Interface moderne arrondie
- **Menu Démarrer centré** : Style macOS (peut être repositionné à gauche)
- **Barre des tâches centrée** : Icônes au centre par défaut
- **Widgets** : Panneau de widgets personnalisables
- **Snap Layouts** : Disposition de fenêtres améliorée (6 layouts)
- **Snap Groups** : Restauration de groupes de fenêtres

**Fonctionnalités système**
- **DirectStorage** : Chargement rapide des jeux (GPU décompression)
- **Auto HDR** : HDR automatique pour les jeux
- **Android Apps** : Exécution d'applications Android (via Amazon Appstore)
- **Focus Sessions** : Gestion de la concentration avec chronomètre

**Productivité**
- **Teams intégré** : Chat et visio directement dans la barre des tâches
- **Copilot** : Assistant IA intégré (depuis 23H2)
- **Améliorations multitâche** : Meilleure gestion écrans multiples

**Sécurité renforcée**
- **TPM 2.0 obligatoire** : Puce de sécurité matérielle
- **Secure Boot obligatoire** : Démarrage sécurisé UEFI
- **VBS activé par défaut** : Virtualization-Based Security
- **HVCI** : Hypervisor-protected Code Integrity

> [!warning] Configuration requise stricte
> Windows 11 a des exigences matérielles plus strictes que Windows 10, notamment TPM 2.0 et processeurs récents (Intel 8ème gen / AMD Ryzen 2000 minimum officiellement).

#### Différences majeures Windows 10 vs Windows 11

| Aspect | Windows 10 | Windows 11 |
|--------|-----------|-----------|
| **Interface** | Menu Démarrer à gauche avec tuiles | Menu Démarrer centré sans tuiles |

| **Widgets** | Actualités et centres d'intérêt | Panneau widgets dédié |

| **Coins arrondis** | Interface carrée | Interface arrondie moderne |
| **TPM 2.0** | Recommandé | **Obligatoire** |

| **Processeur** | Large compatibilité | Intel 8e gen / AMD Ryzen 2000+ |

#### Migration Windows 10 → Windows 11

**Vérifier la compatibilité :**
```powershell
# Outil Microsoft : PC Health Check
# Téléchargeable depuis le site de Microsoft

# Via PowerShell (détection TPM)
Get-Tpm

# Vérifier Secure Boot
Confirm-SecureBootUEFI
# True = Secure Boot activé
# False ou erreur = Secure Boot désactivé ou système BIOS
```

> [!tip] Contourner les restrictions (non recommandé pour production)
> Il existe des méthodes non officielles pour installer Windows 11 sur du matériel non conforme, mais Microsoft ne garantit pas les mises à jour futures dans ce cas.

## 🖥️ Versions Windows Server (2016, 2019, 2022)

Windows Server est le système d'exploitation serveur de Microsoft, conçu pour héberger des services réseau, des applications d'entreprise et gérer des infrastructures IT.

### Modèle de canal de maintenance

Microsoft propose deux canaux pour Windows Server :

**Long-Term Servicing Channel (LTSC)**
- Versions majeures tous les 2-3 ans
- Support mainstream : 5 ans
- Support étendu : 5 ans supplémentaires
- **Total : 10 ans de support**
- Interface Server Core et Desktop Experience
- ✅ Recommandé pour la production

**Semi-Annual Channel (SAC)** - ⚠️ Arrêté depuis 2022
- Versions tous les 6 mois (plus maintenu)
- Support de 18 mois
- Uniquement Server Core
- Destiné aux environnements cloud et conteneurs
- Dernière version : Windows Server version 20H2

> [!info] Focus sur LTSC
> Depuis 2022, Microsoft se concentre exclusivement sur le canal LTSC. Le SAC a été abandonné. Pour votre formation TSSR, concentrez-vous sur les versions LTSC.

### Windows Server 2016

**Date de sortie** : Octobre 2016
**Fin du support mainstream** : Janvier 2022
**Fin du support étendu** : Janvier 2027

#### Innovations majeures

**Conteneurs Windows**
- Support des conteneurs Windows Server et Hyper-V
- Isolation des applications
- Compatible avec Docker
- Images de base : Windows Server Core et Nano Server

**Nano Server**
- Version ultra-légère (400 MB sur disque)
- Pas d'interface graphique
- Gestion à distance uniquement (PowerShell, WMI)
- Idéal pour cloud et conteneurs
- ⚠️ Nano Server comme OS standalone abandonné après 2016

**Virtualisation améliorée**
- **Nested Virtualization** : VM dans VM
- **Hot Add/Remove Memory** : Ajustement RAM à chaud
- **Production Checkpoints** : Snapshots cohérents avec VSS
- **Shielded VMs** : VMs chiffrées avec attestation

**Sécurité**
- **Just Enough Administration (JEA)** : Administration avec privilèges limités
- **Credential Guard** : Protection des identifiants en mémoire
- **Control Flow Guard** : Protection contre exploitation mémoire
- **Encrypted Networks** : Chiffrement réseau SDN

**Stockage**
- **Storage Spaces Direct** : Stockage défini par logiciel
- **Storage Replica** : Réplication synchrone/asynchrone pour DR

#### Rôles et fonctionnalités clés

- Active Directory Domain Services
- DNS Server
- DHCP Server
- Hyper-V
- File and Storage Services
- Remote Desktop Services
- Web Server (IIS 10.0)
- Windows Server Update Services (WSUS)

### Windows Server 2019

**Date de sortie** : Octobre 2018
**Fin du support mainstream** : Janvier 2024
**Fin du support étendu** : Janvier 2029

#### Nouveautés principales

**Hybride avec Azure**
- **Azure Network Adapter** : Extension réseau local vers Azure
- **Azure File Sync** : Synchronisation fichiers on-prem ↔ cloud
- **Azure Backup** : Sauvegarde intégrée vers Azure
- **Azure Monitor** : Supervision unifiée
- **Azure Security Center** : Protection des VMs Azure et on-prem

**Administration**
- **Windows Admin Center** : Interface web moderne de gestion
  - Remplace progressivement Server Manager
  - Gestion de serveurs, clusters, Hyper-V, stockage
  - Accessible via navigateur web
- **System Insights** : IA prédictive pour l'infrastructure
  - Prédiction de capacité
  - Détection d'anomalies

**Virtualisation et Conteneurs**
- Kubernetes sur Windows Server
- Support des conteneurs Linux sur Windows (LCOW)
- Améliorations Hyper-V :
  - Machines virtuelles Gen 2 améliorées
  - Réplication Hyper-V via certificats

**Stockage et réseau**
- **Storage Migration Service** : Migration fichiers vers Server 2019 ou Azure
- **Deduplication** : Sur volumes ReFS (en plus de NTFS)
- **Software Defined Networking** : Améliorations SDN
- **Support de IPv6** : Meilleur support natif

**Sécurité renforcée**
- Windows Defender Advanced Threat Protection (ATP) intégré
- Protection contre exploits améliorée
- Sécurité du noyau

> [!tip] Windows Admin Center
> Windows Admin Center est l'outil d'administration moderne à maîtriser. Il remplace progressivement les outils MMC traditionnels et offre une interface web intuitive.

### Windows Server 2022

**Date de sortie** : Août 2021
**Fin du support mainstream** : Octobre 2026
**Fin du support étendu** : Octobre 2031

C'est la **version la plus récente** et celle recommandée pour les nouveaux déploiements.

#### Innovations majeures

**Sécurité de niveau Secured-core**
- **Secured-core Server** : Protection matérielle renforcée
  - Firmware protection (UEFI Secure Boot)
  - Virtualization-based security (VBS)
  - Protection contre firmware malveillants
- **TPM 2.0 obligatoire** pour certaines fonctionnalités
- **Hardware root-of-trust** : Ancrage matériel de confiance
- **HTTPS et TLS 1.3 par défaut**

**Réseau et connectivité**
- **SMB over QUIC** : SMB via protocole QUIC (sécurisé, fiable)
  - Traversée de firewall sans VPN
  - Chiffrement systématique (TLS 1.3)
  - Idéal pour télétravail et edge computing
- **SMB Compression** : Compression des transferts SMB
- **SMB AES-256 Encryption** : Chiffrement plus fort
- **UDP improvements** : Meilleure performance réseau

**Hybride et Azure**
- **Azure Arc** : Gestion unifiée serveurs on-prem depuis Azure
- **Azure Automanage** : Configuration et maintenance automatisées
- **Hotpatch** : Mises à jour sans redémarrage (Azure Edition)
- **Azure Extended Network** : Extension réseau on-prem vers Azure

**Virtualisation Hyper-V**
- Support de machines virtuelles Gen 2 amélioré
- GPU partitioning pour VDI
- Améliorations performances Hyper-V

**Conteneurs Windows**
- Images de conteneurs plus petites
- Meilleures performances
- Support IPv6 natif
- Intégration Kubernetes améliorée

**Stockage**
- **Storage Replica** : Améliorations de performances
- **Storage Spaces Direct** : Meilleure résilience
- **ReFS** : Améliorations de performance et fiabilité

> [!example] Cas d'usage SMB over QUIC
> Une entreprise avec des travailleurs distants peut leur donner accès aux fichiers du serveur sans VPN. SMB over QUIC sécurise le trafic avec TLS 1.3 et traverse les firewalls sans configuration spéciale.

#### Éditions Windows Server 2022

**Standard Edition**
- Jusqu'à 2 machines virtuelles (VMs) Hyper-V
- Licence par processeur physique (minimum 16 cœurs)
- Toutes les fonctionnalités serveur
- Idéal pour PME et charges modérées

**Datacenter Edition**
- Machines virtuelles Hyper-V **illimitées**
- Licence par processeur physique (minimum 16 cœurs)
- Toutes les fonctionnalités de Standard
- **Storage Replica** (réplication)
- **Storage Spaces Direct** (stockage défini par logiciel)
- **Shielded Virtual Machines** (VMs sécurisées)
- **Software Defined Networking** (SDN)
- Idéal pour datacenters et clouds privés

**Azure Edition** (nouvelle !)
- Exclusivement pour Azure
- Fonctionnalités hybrides avancées
- **Hotpatch** : Mises à jour sans redémarrage mensuel
- Azure Automanage intégré
- Optimisé pour le cloud

> [!info] Choisir entre Standard et Datacenter
> - **Standard** : Si vous avez besoin de 0-2 VMs seulement, ou serveurs physiques
> - **Datacenter** : Si vous virtualisez massivement (>2 VMs), ou besoin de Storage Spaces Direct / SDN

#### Modes d'installation

**Server Core** (recommandé)
- Interface en ligne de commande uniquement
- Empreinte disque : ~4 GB
- Moins de mises à jour
- Surface d'attaque réduite
- Administration via PowerShell, Windows Admin Center
- ✅ Meilleure pratique pour la production

**Desktop Experience**
- Interface graphique complète (GUI)
- Empreinte disque : ~12 GB
- Familier pour administrateurs habitués à GUI
- Plus de mises à jour et de surface d'attaque
- Utile pour apprentissage ou environnements spécifiques

> [!tip] Conversion entre modes
> Il est possible de convertir un serveur entre Server Core et Desktop Experience sans réinstallation complète, via DISM et PowerShell.

## 📄 Éditions et licences

### Modèles de licences Windows Desktop

#### Licences OEM (Original Equipment Manufacturer)

**Caractéristiques :**
- Liée au matériel (non transférable)
- Préinstallée sur les PC neufs (Dell, HP, Lenovo, etc.)
- Coût le plus bas
- Support technique par le fabricant du PC
- ❌ Ne peut pas être transférée vers un autre PC

> [!example] Cas d'usage OEM
> Vous achetez un PC portable neuf avec Windows 11 Home préinstallé. Cette licence OEM est liée à cet ordinateur et ne pourra pas être réutilisée si vous changez de PC.

#### Licences Retail (Boîte / FPP - Full Packaged Product)

**Caractéristiques :**
- Achetée séparément du matériel
- ✅ Transférable vers un autre PC
- Coût plus élevé qu'OEM
- Support Microsoft directement
- Peut être désactivée sur un PC et activée sur un autre

> [!tip] Quand choisir Retail
> Si vous assemblez votre propre PC ou prévoyez de changer régulièrement de machine, une licence Retail est plus flexible car transférable.

#### Licences en volume (VL - Volume Licensing)

**Caractéristiques :**
- Pour les entreprises et organisations (minimum 5 licences généralement)
- Gestion centralisée des licences
- Clés KMS (Key Management Service) ou MAK (Multiple Activation Key)
- Tarifs dégressifs selon le volume
- Gestion via VLSC (Volume Licensing Service Center)

**Programmes de licence en volume :**
- **Open License** : PME (5-250 appareils) - ⚠️ Remplacé par CSP
- **Open Value** : Paiement annuel avec Software Assurance
- **Enterprise Agreement** : Grandes entreprises (>500 postes)
- **CSP (Cloud Solution Provider)** : Achat via partenaires Microsoft

> [!info] Software Assurance
> La Software Assurance (SA) est un contrat de maintenance qui donne droit aux mises à niveau de version, au support technique étendu et à des services additionnels.

#### Licences académiques

**Caractéristiques :**
- Tarifs très réduits pour étudiants et établissements
- Restrictions d'usage (non commercial)
- Programmes : Azure Dev Tools for Teaching (anciennement DreamSpark/MSDNAA)
- Licences complètes et fonctionnelles

### Modèles de licences Windows Server

#### Licence par cœur (Core-based licensing)

Depuis Windows Server 2016, le modèle de licence est basé sur les **cœurs de processeurs**.

**Règles de base :**
- **Minimum 16 cœurs** par serveur physique
- **Minimum 8 cœurs** par processeur physique
- Licences vendues par pack de **2 cœurs** ou **16 cœurs**
- Compte tous les cœurs physiques du serveur

> [!example] Calcul de licences
> **Serveur avec 2 processeurs de 12 cœurs chacun :**
> - Total : 2 × 12 = 24 cœurs
> - Licences nécessaires : 24 cœurs / 2 = 12 packs de 2 cœurs (ou 1.5 pack de 16 cœurs, arrondi à 2)
> 
> **Serveur avec 1 processeur de 4 cœurs :**
> - Total : 4 cœurs physiques
> - Licences nécessaires : Minimum 16 cœurs = 8 packs de 2 cœurs (ou 1 pack de 16 cœurs)

#### Client Access Licenses (CAL)

En plus de la licence serveur, vous avez besoin de **CAL** (Client Access Licenses) pour chaque utilisateur ou appareil qui accède au serveur.

**CAL Device (Par appareil)**
- Une CAL par appareil physique
- N'importe quel utilisateur peut utiliser cet appareil
- Idéal si plusieurs utilisateurs partagent des postes (shifts, hotdesking)

**CAL User (Par utilisateur)**
- Une CAL par utilisateur
- L'utilisateur peut se connecter depuis plusieurs appareils
- Idéal pour utilisateurs nomades (laptop + desktop + smartphone)

> [!tip] Choisir entre Device et User CAL
> - **Device CAL** : Moins d'appareils que d'utilisateurs (ex: centre d'appels avec shifts)
> - **User CAL** : Utilisateurs avec plusieurs appareils (ex: cadres avec PC + laptop + téléphone)

**Types de CAL :**
- **Windows Server CAL** : Accès de base au serveur
- **RDS CAL** : Requis en plus pour Remote Desktop Services
- **Exchange CAL** : Pour Exchange Server (Standard ou Enterprise)
- **SharePoint CAL** : Pour SharePoint Server
- **SQL Server CAL** : Pour SQL Server (alternative au modèle par cœur)

#### Éditions et droits de virtualisation

**Windows Server Standard**
- **2 machines virtuelles** (VMs) ou conteneurs Hyper-V
- Si besoin de plus de 2 VMs → acheter licences Standard additionnelles
- Exemple : 4 VMs nécessitent 2 licences Standard (2×2 VMs)

**Windows Server Datacenter**
- **Machines virtuelles illimitées**
- Une seule licence Datacenter couvre toutes les VMs sur cet hôte
- Idéal pour virtualisation dense

> [!example] Calcul du coût
> **Scénario : Serveur hôte Hyper-V avec 8 VMs Windows Server**
> 
> **Option 1 : Standard**
> - 4 licences Standard (4 × 2 VMs = 8 VMs)
> - Coût : 4 × prix Standard
> 
> **Option 2 : Datacenter**
> - 1 licence Datacenter (VMs illimitées)
> - Coût : 1 × prix Datacenter
> 
> **Point d'équilibre : environ 6-8 VMs** (prix Datacenter ≈ 3-4× prix Standard)

#### Canaux d'acquisition

**Volume Licensing**
- Pour entreprises (min 5 licences)
- Programmes : Open, Open Value, Select Plus, Enterprise Agreement
- Gestion centralisée via VLSC
- Options de paiement flexibles

**OEM**
- Préinstallé par fabricants (Dell, HP, Lenovo, etc.)
- Lié au matériel
- Pas de transfert possible

**CSP (Cloud Solution Provider)**
- Achat via partenaires Microsoft
- Facturation mensuelle possible
- Flexibilité et évolutivité

**Retail / FPP**
- Licence boîte ou téléchargement
- Transférable
- Principalement pour petites structures

### Activation Windows

#### Méthodes d'activation

**Activation en ligne**
- Activation automatique via Internet
- Méthode la plus courante et simple
- Instantanée

**Activation téléphonique**
- Pour machines sans Internet
- Appel du centre d'activation Microsoft
- Saisie de l'ID d'installation et de confirmation

**KMS (Key Management Service)**
- Pour entreprises avec licences en volume
- Serveur KMS local qui active les clients
- Renouvellement automatique tous les 180 jours
- Clients doivent contacter KMS tous les 180 jours
- Minimum 25 clients Windows / 5 serveurs pour activer KMS

**MAK (Multiple Activation Key)**
- Pour entreprises avec licences en volume
- Clé utilisable un nombre fixe de fois
- Activation permanente (pas de renouvellement)
- Idéal pour machines isolées ou peu nombreuses

> [!info] KMS vs MAK
> - **KMS** : Grandes structures, machines connectées régulièrement au réseau interne
> - **MAK** : Petites structures, machines isolées, laptops terrain déconnectés longtemps

#### Vérifier l'activation

```powershell
# Interface graphique
slmgr.vbs /xpr

# Afficher les détails complets
slmgr.vbs /dlv

# État d'activation
slmgr.vbs /dli

# Via PowerShell (Windows 10/11 et Server 2016+)
Get-CimInstance -ClassName SoftwareLicensingProduct | 
    Where-Object {$_.PartialProductKey} | 
    Select-Object Name, Description, LicenseStatus

# LicenseStatus :
# 0 = Unlicensed
# 1 = Licensed (activé)
# 2 = Out-Of-Box Grace Period
# 3 = Out-Of-Tolerance Grace Period
# 4 = Non-Genuine Grace Period
# 5 = Notification
```

#### Résolution des problèmes d'activation

**Erreurs courantes :**
- **0x8007232B** : DNS ne peut pas résoudre le serveur KMS
- **0xC004F074** : Serveur KMS indisponible
- **0xC004C003** : Serveur d'activation ne peut être contacté
- **0xC004C008** : Clé de produit déjà utilisée (limite atteinte)

**Dépannage :**
```powershell
# Réinitialiser l'état d'activation
slmgr.vbs /rearm

# Spécifier un serveur KMS manuellement
slmgr.vbs /skms kms-server.domain.local:1688

# Forcer la tentative d'activation
slmgr.vbs /ato

# Désinstaller la clé de produit
slmgr.vbs /upk

# Installer une nouvelle clé
slmgr.vbs /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
```

### Processeurs : Architectures et générations

#### Architectures supportées

**x86 (32 bits)**
- Abandonné pour Windows Server depuis 2008 R2
- Abandonné pour Windows 11 (64 bits uniquement)
- Windows 10 supporte encore 32 bits (version x86)
- ⚠️ En voie de disparition, éviter pour nouveaux déploiements

**x64 (64 bits / AMD64 / x86-64)**
- Architecture standard actuelle
- Adressage de >4 GB de RAM
- Performances supérieures
- Support de fonctionnalités de sécurité avancées (DEP, ASLR, etc.)
- **Recommandé pour tous nouveaux systèmes**

**ARM64 (architecture ARM 64 bits)**
- Windows 10/11 sur processeurs ARM (ex: Surface Pro X)
- Émulation x86/x64 pour compatibilité applicative
- Consommation énergétique réduite
- Windows Server ne supporte pas ARM (sauf versions spéciales IoT)

> [!info] Transition vers ARM
> Microsoft pousse progressivement ARM pour Windows Desktop (efficacité énergétique), mais x64 reste dominant. Windows Server reste exclusivement x64.

#### Extensions processeur importantes

**Virtualisation matérielle**
- **Intel VT-x** (Intel Virtualization Technology)
- **AMD-V** (AMD Virtualization)
- Obligatoire pour Hyper-V et la plupart des hyperviseurs
- Activable dans le BIOS/UEFI

**SLAT (Second Level Address Translation)**
- **Intel EPT** (Extended Page Tables)
- **AMD RVI** (Rapid Virtualization Indexing)
- Améliore performances de virtualisation
- Requis pour Hyper-V Client (Windows 10/11)
- Processeurs Intel Core i3/i5/i7 1ère génération+

**NX bit / XD bit (Execute Disable)**
- **DEP** (Data Execution Prevention) dans Windows
- Empêche exécution de code dans zones mémoire données
- Protection contre buffer overflow
- Quasi-universel sur processeurs modernes

**AES-NI (Advanced Encryption Standard New Instructions)**
- Accélération matérielle du chiffrement AES
- Améliore performances BitLocker, VPN, HTTPS
- Présent sur processeurs Intel depuis 2010, AMD depuis 2012

> [!tip] Vérifier support processeur
> Utilisez CPU-Z (utilitaire gratuit) pour voir toutes les instructions supportées par votre processeur : VT-x, EPT, AES-NI, etc.

> [!info] Limites théoriques vs pratiques
> Ces limites sont bien au-delà de ce que les cartes mères grand public supportent actuellement (~128 GB max pour desktop). Elles sont pertinentes pour serveurs professionnels.

#### Types de RAM

**DDR (Double Data Rate)**
- **DDR3** : Ancien standard (jusqu'à 2133 MHz)
- **DDR4** : Standard actuel (2133-3200 MHz typique, jusqu'à 5000+ MHz OC)
- **DDR5** : Nouvelle génération (4800-6400 MHz+), processeurs récents

**ECC (Error-Correcting Code)**
- Détection et correction d'erreurs mémoire
- **Obligatoire pour serveurs critiques**
- Support processeur et carte mère nécessaire (Xeon, EPYC)
- Processeurs grand public (Core i, Ryzen non-Pro) ne supportent généralement pas ECC

> [!warning] RAM pour serveurs
> Pour Windows Server en production, **utilisez toujours de la RAM ECC** pour éviter la corruption de données en mémoire. Un serveur de fichiers ou contrôleur de domaine avec RAM non-ECC est un risque.

### Stockage

#### Types de stockage

**HDD (Hard Disk Drive)**
- Disques mécaniques traditionnels
- Capacité élevée (jusqu'à 20+ TB)
- Prix au GB le plus bas
- Vitesse : 80-160 MB/s (lecture séquentielle)
- ⚠️ Lent pour système d'exploitation
- ✅ Bon pour stockage de masse / archivage

**SSD SATA (Solid State Drive)**
- Disques flash en interface SATA III (6 Gbps)
- Vitesse : 500-550 MB/s (lecture/écriture séquentielle)
- Latence très faible vs HDD
- ✅ Excellent pour OS, applications
- Prix modéré

**SSD NVMe (Non-Volatile Memory Express)**
- Interface PCIe (beaucoup plus rapide que SATA)
- Vitesse : 2000-7000 MB/s selon génération PCIe
  - **PCIe 3.0** : jusqu'à ~3500 MB/s
  - **PCIe 4.0** : jusqu'à ~7000 MB/s
  - **PCIe 5.0** : jusqu'à ~14000 MB/s (émergent)
- ✅ Optimal pour OS, applications, VMs
- Plus cher que SATA

> [!tip] Recommandation stockage
> **Desktop** : SSD SATA minimum pour OS, HDD pour données volumineuses
> **Gaming / Workstation** : SSD NVMe pour OS et jeux/apps
> **Serveur** : SSD NVMe ou SAS en RAID pour performances et fiabilité

#### RAID (Redundant Array of Independent Disks)

Pour serveurs, le RAID est essentiel pour fiabilité et/ou performances.

| Niveau RAID | Minimum disques | Capacité utilisable | Redondance | Usage |
|-------------|----------------|---------------------|-----------|-------|
| **RAID 0** | 2 | 100% (n × taille) | ❌ Aucune | Performance pure (éviter en prod) |
| **RAID 1** | 2 | 50% (taille 1 disque) | ✅ 1 disque peut échouer | OS serveur, données critiques |
| **RAID 5** | 3 | (n-1) × taille | ✅ 1 disque peut échouer | Stockage général |
| **RAID 6** | 4 | (n-2) × taille | ✅ 2 disques peuvent échouer | Grandes capacités, sécurité élevée |
| **RAID 10** (1+0) | 4 | 50% (n/2 × taille) | ✅ 1 disque par miroir | Hautes performances + redondance |

> [!warning] RAID n'est pas une sauvegarde
> Le RAID protège contre la défaillance matérielle d'un disque, mais pas contre la suppression accidentelle, la corruption de données, les ransomwares ou les catastrophes. **Sauvegardez toujours vos données !**

### Firmware : BIOS vs UEFI

#### BIOS (Basic Input/Output System)

- Standard ancien (années 1980)
- Interface texte
- Limitation partitionnement MBR (2 TB max par disque)
- Démarrage en mode 16 bits
- ⚠️ Obsolète, éviter pour nouveaux systèmes

#### UEFI (Unified Extensible Firmware Interface)

- Standard moderne (remplace BIOS depuis ~2010)
- Interface graphique possible
- Support partitionnement GPT (disques >2 TB)
- Démarrage plus rapide
- **Secure Boot** : Vérification signatures pour empêcher bootkits
- Requis pour Windows 11

> [!info] Secure Boot
> Secure Boot est une fonctionnalité UEFI qui vérifie que seuls des systèmes d'exploitation signés par des clés approuvées peuvent démarrer. Cela empêche les rootkits et bootkits de s'exécuter avant le système.

**Vérifier le mode firmware :**
```powershell
# PowerShell
$env:firmware_type

# Ou via msinfo32
msinfo32.exe
# Rechercher "Mode BIOS" : Devrait indiquer "UEFI" ou "Héritage"
```

### TPM (Trusted Platform Module)

#### Qu'est-ce que le TPM ?

Le **TPM** est une puce de sécurité matérielle qui stocke des clés cryptographiques, des certificats et mesure l'intégrité du système.

**Versions :**
- **TPM 1.2** : Ancienne version, support de base
- **TPM 2.0** : Standard actuel, requis pour Windows 11

#### Fonctionnalités du TPM

- **Stockage sécurisé de clés** : Clés BitLocker, certificats
- **Attestation** : Preuve que le système n'a pas été altéré
- **Measured Boot** : Mesure de chaque composant au démarrage
- **Secure Boot** : En combinaison avec UEFI

> [!warning] TPM obligatoire Windows 11
> Windows 11 exige **TPM 2.0** activé. Sans TPM 2.0, l'installation échouera (sauf contournements non supportés).

**Vérifier présence TPM :**
```powershell
# PowerShell
Get-Tpm

# Résultat attendu :
# TpmPresent : True
# TpmReady : True
# TpmEnabled : True
# TpmActivated : True

# Interface graphique
tpm.msc
```

**Activer TPM :**
Le TPM s'active dans les paramètres UEFI/BIOS de la carte mère. Cherchez dans Security ou Advanced :
- Intel : "Intel PTT" (Platform Trust Technology)
- AMD : "AMD fTPM" (firmware TPM)
- TPM discret : "TPM Device" ou "Security Device"

## 📚 Résumé

### Points clés à retenir

> [!info] Histoire de Windows
> Windows a évolué de simples shells graphiques sur MS-DOS (années 1980-90) vers des systèmes d'exploitation robustes basés sur l'architecture NT. Windows XP et Windows 7 ont marqué des sommets de popularité.

> [!info] Windows 10 et 11
> Windows 10 (2015-2025) a introduit le modèle "Windows as a Service" avec mises à jour continues. Windows 11 (2021) apporte une refonte visuelle et des exigences matérielles strictes (TPM 2.0, UEFI, processeurs récents).

> [!info] Windows Server
> Les versions serveur suivent un cycle LTSC avec 10 ans de support. Server 2022 est la version actuelle avec des fonctionnalités de sécurité avancées (Secured-core) et d'hybridation cloud (Azure Arc, SMB over QUIC).

> [!info] Éditions et licences
> Les éditions Desktop se déclinent en Home, Pro, Pro for Workstations et Enterprise. Les serveurs ont Standard (2 VMs) et Datacenter (VMs illimitées). Les licences serveur nécessitent aussi des CAL utilisateur ou device.

> [!info] Matériel
> Windows 11 impose des exigences strictes : processeurs récents (Intel 8e gen / AMD Ryzen 2000+), TPM 2.0, UEFI Secure Boot, 4 GB RAM minimum. Les serveurs nécessitent du matériel professionnel avec RAM ECC et RAID.

### Pièges courants

> [!warning] Erreurs fréquentes
> - ❌ Installer Windows 11 sans vérifier TPM 2.0 et Secure Boot
> - ❌ Utiliser des licences OEM pour migrations de matériel
> - ❌ Sous-dimensionner la RAM des serveurs (512 MB n'est pas suffisant !)
> - ❌ Déployer des serveurs de production sans RAM ECC
> - ❌ Oublier les CAL dans le calcul de licences Server
> - ❌ Confondre Standard et Datacenter pour virtualisation dense

### Bonnes pratiques

> [!tip] Recommandations
> - ✅ Privilégier Windows 11 pour nouveaux PC (support plus long)
> - ✅ Choisir Windows Server 2022 pour nouveaux serveurs
> - ✅ Utiliser Server Core pour sécurité et performances
> - ✅ Vérifier la compatibilité matérielle avant migration Windows 11
> - ✅ Documenter les licences et activations (clés, serveur KMS)
> - ✅ Utiliser SSD NVMe pour OS, RAID pour serveurs
> - ✅ Activer TPM 2.0 et Secure Boot dans UEFI
> - ✅ Prévoir RAM suffisante selon les rôles serveur
